# 📚 College Schedule

Приложение для удобного получения уведомлений о предстоящих занятиях и добавления занятий, отсутствующих в обычном расписании колледжа.

Приложение автоматически получает актуальное расписание, сохраняет его локально и отображает ближайшие занятия в удобном интерфейсе.

---

## ✨ Возможности

* 📅 Просмотр расписания занятий
* 🔄 Автоматическое обновление расписания
* 🔔 Уведомления о предстоящих занятиях
* ➕ Добавление занятий, отсутствующих в обычном расписании
* ⚙️ Настройки приложения
* 📄 Просмотр логов работы
* 🔐 Авторизация через аккаунт колледжа
* 💾 Локальное хранение настроек и расписания

---

## 🛠️ Установка

### 1. Установите Python

Для работы приложения требуется **Python 3.14 или новее**.

Проверить установленную версию можно командой:

```bash
python --version
```

### 2. Скачайте проект

Клонируйте репозиторий:

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd <ПАПКА_ПРОЕКТА>
```

Также можно скачать проект архивом с GitHub и распаковать его вручную.

### 3. Установите зависимости

Перейдите в папку проекта и выполните:

```bash
pip install -r requirements.txt
```

### 4. Установите браузер для Playwright

Приложение использует **Playwright** для авторизации в аккаунте колледжа.

Если в логах появляется ошибка, связанная с отсутствием браузера, выполните:

```bash
playwright install chrome
```

Если команда `playwright` не найдена, используйте:

```bash
python -m playwright install chrome
```

После установки браузера попробуйте запустить приложение снова.

### 5. Запустите приложение

После установки всех необходимых компонентов выполните:

```bash
python main.py
```

---

## 🚀 Первый запуск

При первом запуске приложение может запросить данные для входа в аккаунт колледжа.

После успешной авторизации необходимые данные сохраняются локально, и приложение сможет автоматически получать актуальное расписание.

---

## 📄 Логи

Если приложение работает неправильно, первым делом рекомендуется проверить вкладку **«Логи»**.

Логи помогают определить проблемы, связанные с:

* авторизацией;
* получением расписания;
* Playwright и Chrome;
* сетевым подключением;
* обновлением расписания.

---

## ❗ Решение проблем

### `Google Chrome executable was not found`

Если в логах появляется ошибка:

```text
Google Chrome executable was not found
```

установите браузер для Playwright:

```bash
python -m playwright install chrome
```

После завершения установки перезапустите приложение.

### Ошибка при установке зависимостей

Убедитесь, что используется подходящая версия Python:

```bash
python --version
```

После этого повторите установку зависимостей:

```bash
pip install -r requirements.txt
```

Если проблема сохраняется, проверьте вкладку **«Логи»** — там обычно указана причина ошибки.
