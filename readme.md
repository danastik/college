Данное приложение предназначено для удобного получения уведомлений о предстоящих занятиях и добавления занятих, не указанных в обычном расписании.

Приложение автоматически получает актуальное расписание, сохраняет его локально и отображает ближайшие занятия в удобном интерфейсе.


**Возможности:**

📅 Просмотр расписания занятий

🔄 Автоматическое обновление расписания

🔔 Уведомления о предстоящих занятиях

⚙️ Настройки приложения

📄 Просмотр логов работы

🔐 Авторизация через аккаунт колледжа

💾 Локальное хранение настроек и расписания


**Установка**

1. Установите Python

Для работы приложения требуется Python 3.14 или новее.

Проверить установленную версию можно командой:

python --version

2. Скачайте проект

Клонируйте репозиторий:

git clone <URL_РЕПОЗИТОРИЯ>

cd <ПАПКА_ПРОЕКТА>

Либо скачайте проект архивом с GitHub и распакуйте его.

3. Установите зависимости

В папке проекта выполните:

pip install -r requirements.txt

4. Установите браузер для Playwright

Приложение использует Playwright для авторизации в аккаунте колледжа.

Если в логах появляется ошибка, связанная с отсутствием браузера, выполните:

playwright install chrome

После установки попробуйте запустить приложение снова.

Если команда playwright не найдена, можно использовать:

python -m playwright install chrome

5. Запустите приложение

После установки всех зависимостей запустите:

python main.py


**Первый запуск**

При первом запуске приложение может запросить данные для входа в аккаунт колледжа.

После авторизации необходимые данные сохраняются локально, а приложение сможет автоматически получать актуальное расписание.


**Логи**

Если приложение работает неправильно, первым делом рекомендуется проверить вкладку «Логи».

Логи также помогают определить проблемы с:
- авторизацией;
- получением расписания;
- Playwright и Chrome;
- сетевым подключением;
- обновлением данных.


**Решение проблем**

Google Chrome executable was not found

Если в логах появляется ошибка:

Google Chrome executable was not found

попробуйте установить Chrome для Playwright:

python -m playwright install chrome


**Ошибка при установке зависимостей**

Убедитесь, что используется правильная версия Python:

python --version

После этого повторите:

pip install -r requirements.txt

Если проблема сохраняется, проверьте логи приложения — в них обычно указана причина ошибки.
